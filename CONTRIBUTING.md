# Contributing

Contributions to engstoch are welcome - bug reports, new validation cases, notebooks, exercises and methods.

- **Bugs:** please open an issue with a minimal example (seed, code, expected and actual result).
- **New methods:** include a docstring stating the algorithm and its reference, unit tests, and at least one
  validation check in `docs/validate.py` against an independent reference (a closed form, a published value,
  SciPy, or a theorem that the output must satisfy). Statistical checks need a fixed seed and a tolerance of
  several standard errors.
- **Notebooks** are generated from `notebooks/build_notebooks.py`; edit that file and run
  `python notebooks/build_notebooks.py`, never the `.ipynb` files directly. Solutions likewise come from
  `solutions/build_solutions.py`.
- **Course data** are generated by `tools/make_course_data.py` (seed 2026); change the generator, not the CSV files.
- Run `pytest`, `python docs/validate.py` and `ruff check .` before submitting.
